# examples

这个目录用于放置“处理视频”主线相关的样例文件。

当前建议包含：

- `manifest.v1.example.json`：完整 manifest 样例
- `manifest.v1.schema.json`：`ProjectManifest` 与 `ReviewActionCommand` 的 JSON Schema
- `manifest.types.example.ts`：TypeScript 类型样例
- `manifest.models.example.py`：Python Pydantic 模型样例
- `review-actions.example.md`：review action 的请求/响应与伪代码样例

后续还可以继续加入：

- CLI 调用示例
- 配置文件示例
- 导出结果样例（EDL、FFmpeg 切分命令、时间戳列表）
